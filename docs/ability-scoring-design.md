## 1. 評価対象

- 能力は系列（I・II・III・IV）で来る。**I→II、III→IV は上位だけ**を評価する。
  **II と IV は別個体から得られるので並列**に評価する
- 序・破・急（古代トチカのちから、執事の心得）は別能力として3つとも評価する
- 下位段階は `superseded: true` を付けて評価とTierの母数から外す。解析はする（表示用に残す）
- 実測（2026-09-17）：1,248件中 評価対象 829件。うちカード日付あり 417件、直近1年 250件

## 2. 説明文の構造

説明文は `<br>` 区切りの行で、各行が「条件・トリガー → 効果」の形をしている。
語彙は有限で、パーサはこの表で読む。

### 2-1. 適用条件（hard）：誰が使えるか

角括弧 `[ ]` の自身属性。**カードTierにだけ効き、モンスターページの評価には効かない**
（そのモンスターが使えるかどうかを決めるだけ）。

| 形 | 例 |
|---|---|
| オーラ | `[自身赤]` `自身<オーラ緑>で` |
| モン類 | `[怪物]` |
| 血統 | `[主血統ガリ]` `[アーク種]` |
| または／かつ | `[自身赤または主血統ガリ]` `[青またはアーク種]` `[白または魔族]` |

### 2-2. 技条件（soft）：使う技の側の条件

`＜赤＞技発動時` のように**技の色・種類**にかかる条件。モンスターのオーラではない。
技DBがある血統は「その血統に赤技があるか」で判定でき、無い血統はオーラ一致で代用する（第2段）。

| 項目 | 例 |
|---|---|
| aura | `＜赤＞技` `＜オーラ黄＞技` `＜黒または無＞技` |
| stance | `＜オーラ有利＞技` `＜オーラ不利以外＞技` `＜オーラなし＞技` `オーラ技` |
| type | `＜ちから＞技` `かしこさ技` |
| rank | `R4以上の` |
| aptitude | `間合い適性S以上` `SS以上：` |
| range／position | `＜零距離＞技` `＜前衛＞技` |
| repeat | `1つ前と同じ技を使用したとき` |

### 2-3. 状況条件：いつ効くか（両方のTierに効く）

| 種別 | 語彙 |
|---|---|
| time | 序盤／前半／中盤／後半／終盤 |
| stance | 有利／有利以外／不利以外／自身有利／オーラ有利／モン類有利 |
| terrain | 砂漠／森林／海岸／雪山／火山（基礎データの地形適性と接続できる） |
| weather | 晴れ／曇り／悪天候 |
| position | 前衛／後衛／遠・中・近・零距離 |
| opponent | 相手黒／相手魔族／相手が＜オーラ緑＞のとき |
| state | 状態変化／怒 |
| compare | 相手より◯◯が高いと |
| life | ライフ50%未満／残りライフが少ないほど／ライフが100%の時 |
| probability | ＜40%＞の確率で／稀に |
| stack | スタック／回数に応じて／地形適性に応じて |
| while | この能力のシールド破壊まで／発動中 |
| numeric | 最大耐久値100／最大値+100（効果の上限。条件ではないが角括弧で来る） |
| size | 自身＜小さい＞で |

### 2-4. トリガー

技発動時／技命中時／技非命中時／被ダメ時／回避時／クリティカル時／バトル開始時／シールド破壊時

### 2-5. 効果原子（大分類6・中分類）

| 大分類 | 原子語 |
|---|---|
| 火力 | 与ダメ上昇／クリ率上昇／クリダメ上昇／クリ確定／追撃／連撃／攻撃ステ加算／技性能上昇／貫通／ステ上昇（ちから・かしこさ・攻撃ステ） |
| 命中 | 必中／命中率上昇／ステ上昇（命中） |
| 回避・防御 | 完全回避／回避率上昇／被ダメ低下／被ダメブロック／クリ無効／シールド展開／食いしばり／ステ上昇（回避・丈夫さ・ライフ） |
| ガッツ | ガッツ回復／ガッツダメ上昇／ガッツダメ低下／消費ガッツ |
| 弱体 | 相手ステ低下／相手被ダメ上昇／相手ガッツ停止／相手ガッツ減少／相手忠誠度減少／シールド破壊／封じ／デバフ付与 |
| 支援 | バフ付与／無効化・解除／オーラ変貌／適性効果上昇／ライフ回復／技ステ上昇／ステ変換 |

- **ステ上昇は「どのステが・何項目」で分ける**。`stats` を持ち、大分類は `STAT_CATEGORY` で決まる。
  全ステは6項目（「ライフを除く」なら5項目）として火力・命中・回避防御の全部に効く
- 数値は `value` と `unit`（`Lv`／`%`／`pt`／`large`＝「大上昇」）で持つ
- 角括弧で付与されるバフ（`[強撃Lv1]を付与` `[被ダメ-20%<20秒>]を付与`）は条件ではなく効果。
  中身を同じ原子語で解析し `granted: true` を付ける

### 2-6. 回数と秒数

| 表記 | 意味 | 持ち方 |
|---|---|---|
| **追撃・連撃に隣接する** `＜N回＞`（`＜1回＞追撃`／`追撃＜2回＞`／`追撃を＜1回＞与える`／`連撃Lv1×1回`） | **ヒット数**。トリガーごとに毎回 | `hits` |
| それ以外の `＜N回＞`（行末など） | **試合中の発動回数制限** | `limit` |
| `何回でも`／`各オーラ種毎に1回` | 制限なし／種別ごと | `limit: 'unlimited'` ／ `{per, n}` |
| `＜最大N回＞` `累積N回まで` | 上限・スタック | `maxStack` |
| `＜N秒＞`／`＜永続＞` | 継続 | `duration` |

ヒット数は数値係数に掛ける（10%×2回＝20%）。回数制限は補正で割り引く。
「追撃を＜1回＞与える」がヒット数であることは管理者確認済み（2026-09-17）。

## 3. 評価（第2段。値は未定）

```text
行の評価   = base[原子語] × valueScale(数値) × statCount(項目数) × hits × Π modifiers(条件・トリガー・回数・秒数)
能力の評価 = 行の合計（同じ原子語は逓減）
power      = 能力の評価。手入力は ability-overrides.json の上書きだけ
```

- **適用条件（hard）は power に織り込まない。**カードTierの側で「使える体の割合」として掛ける
- 状況条件・技条件・トリガー・回数・秒数は power に織り込む（そのモンスターにとっても効く場面が限られるため）

```text
能力Tier（モンスターページ）  = 現役プール内の power の相対位置
カードTier（アシストカード）  = 現役プール内の power × 適用範囲 の相対位置
```

- Tierは1本。分類ごとに分けない。分類は表の列として見せる
- 現役プール＝カード日付が直近N か月（既定は12か月案）＋ `ability-overrides.json` の手動フラグ
- 新しい強い能力には大きい値が自動で付き、Tier境界が上がる。旧能力の値は触らない
- モンスターページは Tier順の表（能力名・分類・条件・入手カード）＋「Tier1 n件／Tier2 n件」＋分類別の最高Tier。
  1本の総合点にはしない

基準値・係数を決めるときは、具体的な対（「必中Lv2＜1回＞ vs 与ダメ上昇Lv7」など）を並べて決め、
`ability-rubric.json` と本章を同じPRで更新する。
