# docs/ の使い方

開発ルールのうち、**ドメイン知識・データの規則**を置く場所です。
開発環境そのもののルール（読み込み禁止、変更禁止、報告形式など）は `AGENTS.md` にあります。

## 使い分け

| 種類 | 置き場所 | 例 |
|---|---|---|
| 開発環境のルール | `AGENTS.md` | 読み込み禁止、ブランチ運用、完了報告 |
| ドメインの規則 | `docs/*.md` | ID採番、血統の並び順、URL設計 |
| コンテンツ運用手順 | `CLAUDE.md` | ガチャ更新、日記追加 |

## ファイルを追加したら

**必ず `AGENTS.md` 第1章の索引に1行追加してください。**
索引に載っていないファイルは、エージェントに読まれません。
