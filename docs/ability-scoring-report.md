## 0. この採点の目的と前提

### 0-1. モンスター側に掲載するための採点である

この採点は、**モンスター詳細ページの「相性のいいアシスト能力」に載せる能力を選ぶため**のものです。
ある1体のモンスターから見て「この能力を発動できたら、どれだけ戦いが有利になるか」を点数にしています。

そのため、次のものは**点数に入れていません**。

- **その能力を使えるモンスターの範囲（＝汎用性）**
  `[自身赤]` `[怪物]` `[主血統ガリ]` のような適用条件は、「その体が使えるかどうか」を決めるだけで、点数を下げません。
  「赤の体しか使えないから弱い」とはしません。赤の体のページに載せる時点で、その体は使えるからです。
- 汎用性は**アシストカードの評価だけに使うべきもの**です。カードは「何体に刺さるか」で価値が変わりますが、
  モンスターのページでは、そのモンスターにとっての強さだけが意味を持ちます。
  （将来のカードTier ＝ 能力の点 × 使える体の割合、として別に扱う設計です）

一方、**「いつ・どれだけ効くか」を決める条件は点数に入れています**。
時間帯（序盤・終盤）、有利・不利、残りライフ、技の色（`<赤>技発動時`）、トリガー（技命中時など）、回数（`<1回>`）、秒数（`<20秒>`）などです。
その体にとっても、効く場面が限られるからです。

### 0-2. 点数の物差し

- **与ダメ上昇Lv1 ＝ 1点**。すべての効果をこの物差しに換算して足します
- ゲーム内ヘルプより、**与ダメ上昇・被ダメ上昇・命中率上昇・クリ率上昇は1Lv＝1.8%**
- ページには**点数・順位・Tierを出しません**。選んだ5件を、番号を振らずに発売が新しい順に並べます
  （「TOP5」と順位を付けると、人によって評価に違和感が出るため）

### 0-3. 試合の前提（すべての換算の土台）

| 項目 | 置いた値 | 根拠 |
|---|---|---|
| 命中率 | 60% | ステ差によるが平均として |
| 試合中の技の回数 | 6回 | 自然回復約2.5/秒×60秒≒150ガッツ、平均消費30 |
| メインダメージ | 2,500 | 2,000〜3,000が普通（インフレ環境） |
| ステータスの基準 | お互い1,500 | 差で見る |
| クリ率・クリ倍率 | 30%・1.5倍 | |
| 決着 | **2発当てたら勝てる駆け引き** | ダメージがインフレした環境 |

## 1. 強力と判断した能力と、その理由・加点の仕方

### 1-1. なぜ「必中」「完全回避」を最も強いとするか

このゲームでは、1発が当たるか外れるかの差が、ダメージの差よりはるかに大きいと判断しました。理由は3つです。

1. **ダメージのインフレで「2発当てたら勝てる」駆け引きになっている**
   1発を確定で当てる・確定で避けることが、そのまま勝敗に直結します。確率を上げる常時効果（命中率+30%など）とは別格です。
2. **ガッツの流れ**
   技の発動時にガッツを消費し、モーション中（数秒〜長いと6秒）は自分のガッツが回復せず、相手のガッツは回復します。
   避けられるとダメージが0になるだけでなく、ガッツ差が開いて相手の反撃機会が増え、次の技までガッツを貯め直す必要も出ます。
3. **ガッツダメージ**
   ダメージとガッツダメージは技の発動時に計算され、当たれば確定でガッツを削れます。

**加点の仕方**

| 効果 | 1回あたりの点 | 補足 |
|---|---:|---|
| 必中 | **125点** | 「命中率+30%（常時）」の1.5倍として決めた |
| 完全回避 | **必中の1.5倍＝187.5点** | 1回あたりでも順位でも、完全回避の方が強い（管理者判断） |
| Lvの補正 | Lvごとに+20% | Lvは強さではなく「ぶつかった時の勝ち負け」（必中は奇数Lv・完全回避は偶数Lv固定で、高い方だけが効く） |
| 回数 | `<1回>`は1回分。回数の付かないものは**3回分で頭打ち** | 2発で決着する環境なので、3発目以降の価値は小さい |
| 「発動技と次の技が必中」 | 2回分 | 文末の「さらに…<1回>」は効果全体にかかる（俺が仕留める II は最大2発） |
| ランダムで付く必中 | **確定の半分** | いつ付くか選べず、狙った技に乗るとは限らない（巫女の占い II） |

例：完全回避Lv2<1回>（技発動時）＝ 125 × 1.5 × 1.2（Lv2）× 0.9（技発動時）≒ 202点

### 1-2. 同じく強力とした防御効果

| 効果 | 点 | 理由 |
|---|---|---|
| **食いしばり**（ライフ1で耐える<1回>） | 1回125点（完全回避1回相当） | 2発決着の環境で、倒される1発を確実に耐える。超根性は「稀に」を×0.6（体感50〜70%発動） |
| **被ダメカット**（最大ライフ20%以上の被ダメをカット） | 1発あたり 125 × 0.6 ×（1−20%）× 防御倍率1.5 | 「その1発で倒されない」に近い。ただしガッツダメージは受け、相手の命中時能力も発動するので完全回避より弱く |
| **被ダメ低下・ブロック全般** | 同じ%の与ダメ上昇の**1.5倍** | 攻守は対称だが、防御側をもう少し強く見る（管理者判断）。ブロックは追撃・連撃にも効くので被ダメ低下のさらに1.2倍 |
| **装甲**（ブロック75%、被弾ごとに15%減少） | 被弾約3.6回の平均（約55%）で計算 | ロボトルファイト！IV |

### 1-3. 相手のガッツを止める効果

| 効果 | 点 | 理由 |
|---|---|---|
| 1ガッツ | **与ダメLv0.56** | 技1発の機会（Lv16.7）÷ 平均消費30 |
| 相手の回復停止・回復速度0・消費ガッツ固定 | 奪うガッツ × **3倍** | 発動すると相手の反撃機会を一気に減らせる（管理者判断）。例：最初の消費ガッツを70に固定＝67点 |
| 相手のガッツを0にする<1回> | 56点 | 「ダメージ0・ガッツダメ100の技が当たった」相当。完全回避ほどではない |

### 1-4. 確率を上げる効果・ステータス

| 効果 | 換算 |
|---|---|
| 命中率・回避率+X% | 期待ダメージ +X÷60 に、命中の価値倍率 **M＝1.5** を掛ける。命中率+30%（常時）＝ Lv41.7 |
| 命中・回避ステ | お互い1,500を基準に、+100で命中率±3%。上げ幅が大きいほど差が開く（(上げ幅÷100)^1.3） |
| 攻撃ステータス+X% | 与ダメ+X%と同等で、追撃も一緒に伸びるので×1.2 |
| 重ねがけ・累積 | 上限の値で持ち、累積の割引（一般×0.6、「〜する度に」×0.8、「技の発動回数に応じて1回+10%」は平均75%） |

## 2. 採点の式

```
行の点   ＝ 効果の値 × 稼働率または回数 × 条件の補正 × トリガーの補正 × 技条件の補正
能力の点 ＝ 行の点の合計（同じ効果は 1・0.7・0.5 と逓減。デメリットは差し引く。下限0）
```

### 2-1. 主な補正

| 種類 | 補正 |
|---|---|
| 時間帯（試合が続いている確率 1.0／0.7／0.45 で重み付け） | 序盤0.47・前半0.63・中盤0.33・後半0.37・終盤0.21 |
| 有利（`[有利]` `<有利>技発動時`） | 0.31（オーラかモン類のどちらかが有利。6分の1ずつ） |
| オーラ有利・モン類有利だけ | 0.17 |
| 残りライフ | 30%以上0.85・50%以上0.7・70%以上0.5・100%0.35／50%以下0.25・30%以下0.15・10%以下0.05 |
| 地形 | 0.2（月次の大会ごとに固定） |
| トリガー | バトル開始時1.0・技発動時0.9・技命中時／被ダメ時0.8・回避時0.5・クリティカル時0.4・シールド破壊時0.3 |
| 技の色（`<赤>技発動時`） | 技DBのある体は「その色の技の割合」、無い体は0.5 |
| 間合い適性S以上 | 0.35（届かない距離では発動しない）。基礎データのある体は、開始時の間合い適性C以上なら届く、Dは0.25 |
| 秒数 | 効いている時間を、時間帯の重みで割合にする（バトル開始時<20秒>＝0.47） |
| 一定時間 | 20秒とみなす |

### 2-2. 読み方のルール（読み違いを防ぐため）

- 系列は上位だけを評価（I→II、III→IV。IIとIVは並列。序・破・急は3つとも）
- 追撃・連撃に隣接する`<N回>`はヒット数、それ以外は試合中の回数制限
- 秒数の無い付与は試合中ずっと続く。`<N回>`付きの付与は重ねがけ
- 「、さらに」の後ろは別の効果（後ろの条件は前の効果にかからない）
- 行の途中の適用条件（料理人 II の`[自身黒]必中`）は、合わない体ではその行を数えない
- 相手の技の色（`相手<オーラ緑>技`）・相手の属性（`相手[創造]`）は相手の条件
- 「AとB」（回避ステと丈夫さステ、クリ率とクリダメ）は両方に効く
- 移動速度は0点。状態変化（超〜）はページに載せない

### 3-4. ページへの反映

- 載せるのはイベントで獲得できる能力だけ（閃き・EXトレ・状態変化は載せない）
- 体ごとに点の上位5件を選び、**番号なし・発売が新しい順**で表示
- 白オーラ48体すべてで「データ操作 II」と「ライラックの花 II」の両方が載ることを確認
- インデックス条件は「解説があって可視1,000字以上、または基礎データあり」（能力の字数だけでは昇格させない）。対象は99件
