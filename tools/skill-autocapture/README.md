# 技の自動撮影（血統技図鑑）

MacのiPhoneミラーリングに映した「血統技図鑑」を自動で操作し、1血統の共通技をすべて撮る。
読み取り（TSVへの転記）はスキル `monster-skill-capture` で行う。ここは撮るところまで。

2026-10-13 にメタルナー種（13技）で試作し、13/13・約7分で撮れた。

| 物 | 役割 |
|---|---|
| `skillcap.py` | 本体。技図鑑の血統一覧から血統を開き、全マスを撮る |
| `overview.py` | 撮影結果を1枚の一覧画像（`overview.png`）にする。`skillcap.py` が最後に呼ぶ |
| `jocr.swift` | 日本語の文字認識（Vision）。画面の見出しを読んで、今どの画面かを確かめる |

## 前提

- スマホの操作は相性検証の道具（`~/claude/lmf-aisho/bin/ctl.sh` と常駐の `LMFCtl.app`）を借りる。
  **`LMFCtl.app` は作り直さない**（アクセシビリティと画面収録の許可が外れる）
- Python は `~/claude/lmf-aisho/analysis/.venv/bin/python`（numpy・Pillow 入り）
- `jocr` は初回だけビルドする。バイナリはコミットしない

  ```bash
  swiftc -O tools/skill-autocapture/jocr.swift -o tools/skill-autocapture/jocr
  ```

  `lmf-aisho/bin/ocr` は日本語が化ける（認識の版が古い）ので使わない

## スマホの取り合い

スマホは相性検証チームと共有。撮る前に `~/claude/lmf-aisho/ops/phone.lock` を作り、終わったら消す。
`skillcap.py` は phone.lock に「技登録」の文字が無いと動かない。相性検証の撮影中（phone.lock が他班のもの・
night.sh が動いている）は使わない。

```bash
printf '技登録の自動撮影（責任者許可）\t%s\t<血統>\n' "$(date '+%Y-%m-%d %H:%M')" > ~/claude/lmf-aisho/ops/phone.lock
```

## 使い方

ゲーム画面を「技図鑑」（血統の一覧）にしてから回す。

```bash
~/claude/lmf-aisho/analysis/.venv/bin/python -u tools/skill-autocapture/skillcap.py メタルナー
```

すでにその血統の「血統技図鑑」を開いている場合は、技図鑑カードの技数（`13/13` の右）を2つ目の引数で渡す。

出力は `~/Pictures/lmf-capture/skills/auto/<血統>-<日時>/`。

```text
NN-top.png       図鑑トップ（技登録条件の★・登録可能なモンスター）
NN-detail.png    技詳細
NN-abK.png       能力詳細（技効果欄の左上→右下の順）
icons/NN.png     技アイコン（技詳細から 123x124px で切り抜き）
manifest.tsv     どのファイルがどの技のどの画面か。技名は文字認識の目安で、正は画像
overview.png     一覧画像
```

撮れた数が技図鑑の技数と合わなければ、終了コード2で止まる。

## 1技の流れ

1. マスをタップ → 上部の技が切り替わったら撮る（図鑑トップ）
2. 同じマスを長押し → 「技詳細」を撮り、アイコンを切り抜く。**長押しでは上部の選択は切り替わらない**ので、1が先
3. 技効果の能力ボタン（2列×最大3段）を左上→右下の順に押し、「能力詳細」／「技能力詳細」を撮って「とじる」
4. 技詳細を「とじる」

画面が変わるたびに見出しの文字（技図鑑・血統技図鑑・技詳細・能力詳細）を読んでから次を押す。
思った画面でなければ止まる。押す位置は y=300〜1440px（画像px）の中だけ。下のメニュー（ガチャなど）と
戻るボタンは押さない。

## 実測で分かったこと（2026-10-13）

- ミラーリング画像は 828×1836px。`ctl.sh` に渡す座標はその半分（pt）
- マス目の列の中心は x=138/313/488/662px（遠・中・近・零）、行の間隔は約149px
- **スクロールは列のすき間（x=113pt）を掴む。**右端はスクロールバーで、掴むと向きが逆になる。
  ドラッグの終点が窓の外に出ると効かない
- 選んだマスは黄色い枠で検出位置が数pxずれる。撮影済みかどうかは、マスの中央を上下にずらして比べ、
  さらに上部の技アイコンでも確かめる
- 文字認識は常駐させる（1回ごとに起動すると2.6秒、常駐で約1.2秒）
- 1技の所要時間は能力0個で約11秒、4個で約38秒
- **解放済みの能力は解放条件が出ない**（灰色にもならず「能力詳細」になる）。画面だけでは
  「条件なし」と見分けられないので、入力者に確かめる

## 技アイコン

`icons/NN.png` は、取り込みで技IDが決まったあと `skill-icons/<技ID>.png` へコピーする。
置けば次の `node build.js` で、血統ページの技チップ・技詳細とモンスター詳細の技の行に出る
（`docs/build-spec.md` 5-9・5-10）。表示の有無はファイルがあるかで決まり、`monster-skills.json` の `icon` 列は null のまま。
画像は作り直さず、撮影したものをそのまま置く。技DBに無い技IDの画像を置くと `verify.js` がFAILにする。
